# Референс: marketing-studio.pro («Корпорация»)

Сайт пользователя, ориентир по **уровню исполнения и количеству движения**, а не по стилю.
Палитру, шрифты и «досье»-эстетику агентства в Fashion Tours не переносим: у турагентства свой бренд.
Аудит снят 20.11.2026 инструментом `tools/web/audit.cjs`, кадры — в `.out/audit/marketing-studio.pro/` (не в git).

## Стек (по аудиту)

- Next.js, плавный скролл Lenis, один `<canvas>` с WebGL (3D-сцена).
- Шрифты: Geologica (заголовки, вариативный 100–900), Golos Text (текст), IBM Plex Mono (служебные подписи).
- Высота страницы: ~33 800 px на ПК, ~20 700 px на телефоне. Вес ~2,2 МБ на ПК, ~1,7 МБ на телефоне.
- Метрики: полная загрузка 9–15 с, LCP на телефоне ~8,8 с. В консоли ошибка MIME у CSS-чанка и 502 на части ресурсов.

## Приёмы, которые стоит взять

| Приём | Как сделано у референса | Как применить в Fashion Tours |
| --- | --- | --- |
| Вступление по скроллу | Гигантские пиктограммы/логотип масштабируются и пролетают сквозь экран | Самолёт / иллюминатор / посадочный талон пролетают и «раскрывают» сцену |
| 3D-сцена | Светящиеся колонны в WebGL с bloom | Облака, вода, свет — сцена полёта и прилёта (Three.js / React Three Fiber) |
| Огромная типографика | H1 172 px, H2 ~110 px, вариативный шрифт | Журнальная антиква крупным кеглем + выделения маркером |
| Выделения маркером | Фразы на цветной плашке (зелёная, розовая) | Тонкий акцент цветом бренда, без кислотности |
| Кейсы-«досье» | Мокапы ноутбука и телефонов, моно-подписи | «Маршруты»: карточки поездок с картой и фото, мокапы видеообзоров |
| Пошаговый процесс | «Протокол» 01–05 с липкими заголовками | «Как мы организуем поездку» 4 шага |
| Фильтр «когда мы откажем» | Список с переключателями | Не берём: противоречит правилу «не отказываем в заявках» |
| Финальный CTA | Большой блок «Отправить бриф», контакты, бегущий текст | «Обсудить поездку» + Telegram + форма |

## Что делать лучше референса

- LCP на телефоне до 2,5 с: первый экран без WebGL-зависимости, сцена грузится после.
- Нет ошибок в консоли, правильные MIME-типы на сервере.
- Cookie-баннер не перекрывает CTA и первый экран на телефоне.
- `prefers-reduced-motion` → статичная версия.
